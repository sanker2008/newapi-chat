# PTAH · Stitch 界面重构设计稿需求

为 Android 优先的个人 AI 对话与图片创作应用 PTAH 绘制 5 张一致的高保真移动端界面，390 × 844，所有用户文案使用简体中文。此阶段只做设计预览。

视觉方向：温暖、安静、精致的创作工具。暖白 #F8F7F3 背景、白色内容表面、陶橙 #D96735 主色、深炭 #292824 文字。通过留白、字号和色块建立层级，避免重复堆叠卡片、重阴影、装饰性渐变。正文至少 15px，触控区域至少 44px。保持 Android 原生使用习惯。

1. 对话首页：顶栏 PTAH、历史入口、新建对话；简洁欢迎语“从一个想法开始”；三项紧凑快捷操作“聊一个问题 / 创作图片 / 读懂文档”。底部固定输入区，整合智能助手、对话、图像创作模式选择；附件按钮与发送按钮明确。底部主导航为“对话 / 作品 / 设置”。未配置 API 时提供简洁连接入口。
2. 进行中的对话：真实中文问答排版、可折叠工具执行状态、图片附件、复制与手动重试入口。清晰区分生成中、已停止、失败；生成中发送按钮切换为停止。与首页保持同一输入区结构，内容阅读优先。
3. 图片创作与编辑：展示一张大幅作品占位图、版本选择、提示词和参考图入口；操作包含“继续编辑 / 局部重绘 / 保存 / 分享”。局部重绘有画笔、橡皮、撤销、重做及确认入口。使用占位图片区块即可，不额外生成艺术素材。明确正在生成的等待状态，不宣传瞬间完成。
4. 作品库：简洁双列图片网格，按日期组织，顶部标题“作品”与数量；作品细节可查看版本和回到原始对话；空状态提供“开始创作”。缩略图使用中性色占位。
5. 设置：分组呈现“服务连接 / 模型 / 能力设置 / 本地数据”。连接区域包含 API 地址、密码样式 Key、检测连接按钮与结果；对话、图片、联网模型分别选择。能力开关由用户确认，不根据模型名称自动判断。Key 只显示掩码占位，不使用真实凭据。

范围约束：无账号登录、无会员、无积分、无业务后端，不添加未有的产品功能。会话与作品保存在本地。停止仅结束本地等待，上游可能继续计费；将该提示放在相关停止说明内，不在所有页面重复展示技术警告。失败不自动重试收费请求。

请生成相互协调的完整界面，展示各屏完整内容与导航，不要只生成组件清单或文字说明。
